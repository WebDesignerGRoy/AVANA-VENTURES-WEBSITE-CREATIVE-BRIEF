AVANA VENTURES — STATIC WEBSITE

Open index.html in a browser to view the website. Upload index.html, styles.css,
script.js, and the assets folder together to a static web host to publish it.
No framework, build step, or package installation is needed.

Fonts load from Google Fonts when online and fall back to installed serif and
sans-serif fonts when offline. Images are included locally in assets/.

IMPORTANT: The Let's Talk email address (hello@avanaventures.com) is a
placeholder carried over from the existing site. Replace it with your actual
contact address in index.html before publishing.
